# Frontend

The **frontend** is the part of an application that runs in the user's browser and that the user directly interacts with.

For example, in a task-management application:

```
Frontend
├── Login page
├── Dashboard
├── Task list
├── Create-task form
├── Buttons
└── Error/loading messages
```

The frontend is responsible for things like:

- displaying information
- accepting user input
- reacting to clicks
- communicating with the backend
- validating input before sending it
- managing what the user currently sees

# **What is SaaS?**

**SaaS (Software as a Service)** is a software delivery model where you use software over the internet without having to install, maintain, or manage its infrastructure yourself.

Instead of installing and running software on your own computer or server, you access it through a web browser or application.

## **Example**

Think about Google Docs.

- You don't need to install a full document management server.
    
- Google hosts and maintains the software.
    
- You access it through your browser.
    
- Google handles updates, infrastructure, and maintenance.
    

Other examples:

|SaaS Product|Purpose|
|---|---|
|Google Workspace|Documents, spreadsheets, email|
|Slack|Team communication|
|Notion|Notes and project management|
|Salesforce|Customer relationship management|
|Dropbox|Cloud file storage|

## **SaaS vs. Self-hosted**

Imagine you want to use Grafana.

**SaaS:**

- Use Grafana Cloud.
    
- Grafana manages the servers and infrastructure.
    
- You don't need to maintain the installation.
    

**Self-hosted:**

- Install Grafana on your own server using Docker.
    
- You manage updates, configuration, storage, and infrastructure.
    

|Feature|SaaS|Self-hosted|
|---|---|---|
|Infrastructure|Provider manages it|You manage it|
|Installation|Usually unnecessary|Required|
|Maintenance|Provider handles most of it|Your responsibility|
|Access|Usually over the internet|Local network or internet|
|Control|Less infrastructure control|More control|

## **Other Cloud Service Models**

You might also encounter these terms:

- **SaaS:** Software as a Service — You use ready-made software.
    
- **PaaS:** Platform as a Service — You get a platform to build and run applications.
    
- **IaaS:** Infrastructure as a Service — You rent computing infrastructure such as virtual machines and storage.
    

**Simple way to remember:**

- SaaS = Use software.
    
- PaaS = Build software.
    
- IaaS = Rent infrastructure.

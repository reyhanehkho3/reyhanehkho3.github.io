**Low latency** means there is very little delay between an action happening and the system responding to it.

For example:

- **Low latency:** A user clicks a button, and the application responds in 10 milliseconds.
    
- **High latency:** The application takes 3 seconds to respond.
    

In simple terms:

- **Low latency = Fast response / Less delay**
    
- **High latency = Slow response / More delay**
    

Latency is usually measured in milliseconds (ms).

In event streaming, low latency means events are processed and delivered almost immediately after they are generated.

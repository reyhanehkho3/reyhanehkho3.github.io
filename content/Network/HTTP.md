### HTTP Methods (The Basics)

HTTP (Hypertext Transfer Protocol) has several "verbs" that tell the server what kind of action you want to perform:

| Method     | Purpose        | Analogy                               |
| ---------- | -------------- | ------------------------------------- |
| **GET**    | Get data       | "Can I see this?"                     |
| **POST**   | Send data      | "Here's some data, please process it" |
| **PUT**    | Update/replace | "Replace this with new data"          |
| **DELETE** | Remove         | "Delete this"                         |
| **PATCH**  | Partial update | "Update just this part"               |

**Definition:** A module is a **self-contained part of a software system** that groups related functionality together.  
Modules help developers organize large programs into smaller, more manageable pieces.

**Examples:**

1. An e-commerce application has `Payment`, `Users`, and `Products` modules.
2. A Python project has separate modules for authentication and database access.
3. A banking system has an `Account` module and a `Transaction` module.

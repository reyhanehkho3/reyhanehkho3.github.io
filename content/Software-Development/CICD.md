## CI/CD — Continuous Integration / Continuous Delivery

**Definition:** CI/CD is a development practice that automatically **builds, tests, and delivers software** whenever developers make changes.  
It helps teams find problems early and release new versions faster and more reliably.

**Examples:**

1. Developer pushes code → GitHub Actions runs tests → application is built.
2. Tests pass → new version is automatically deployed to a testing server.
3. A company automatically deploys every approved change to its production website.

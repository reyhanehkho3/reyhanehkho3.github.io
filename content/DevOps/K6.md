## What is k6?

**k6** is a tool for **load/performance testing** APIs and applications.

You write a small JavaScript test describing what a virtual user should do:

```
import http from 'k6/http';

export default function () {
  http.get('http://localhost:3000/api/users');
}
```

Then k6 can simulate many users doing that request:

```
             k6
              │
       ┌──────┼──────┐
       ↓      ↓      ↓
     User   User   User
       │      │      │
       └──────┼──────┘
              ↓
         Your API
```

For example:

```
k6 run test.js
```

k6 can tell you things like:

```
Requests:       50,000
Failed:             2%
Average:           120ms
p95:               350ms
p99:               800ms
```

## JavaScript

**JavaScript is the programming language itself.**

You can use it to write logic such as:

```
const name = "Reyhaneh";

console.log(`Hello ${name}`);
```

JavaScript can run in browsers, but it can also run on servers using something like **Node.js**.

Think:

> **JavaScript = the language**

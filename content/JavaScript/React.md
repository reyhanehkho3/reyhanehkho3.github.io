**React is a JavaScript library for building user interfaces.**

It is primarily used on the **frontend**.

For example, you might build:

```
┌──────────────────────────────┐
│ My Social App                │
├──────────────────────────────┤
│                              │
│  Reyhaneh                    │
│  Hello everyone!             │
│                              │
│  ❤️ 42   💬 8               │
│                              │
└──────────────────────────────┘
```

React lets you break the UI into components:

```
App
├── Navbar
├── Profile
├── Post
│   ├── Author
│   ├── Content
│   └── LikeButton
└── Footer
```

A React component might look like:

```
function Welcome() {
    return <h1>Hello!</h1>;
}
```

React is technically called a **library**, although people often casually call it a framework.

Think:

> **React = building the frontend/UI**

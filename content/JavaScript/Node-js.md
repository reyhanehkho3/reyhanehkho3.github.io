**Node.js is a runtime that allows JavaScript to run outside the browser.**

Normally, JavaScript was primarily associated with browsers:

```
Chrome
  ↓
JavaScript
  ↓
Web page
```

Node.js lets you do:

```
Linux / Windows / macOS
        ↓
     Node.js
        ↓
   JavaScript code
```

So you can use JavaScript to create backend programs.

For example:

```
console.log("Server is running");
```

You can run it with:

```
node server.js
```

Node.js provides things that browser JavaScript doesn't normally have, such as access to files, networking, processes, etc.

**Important:** Node.js is **not a framework**.

> **Node.js = JavaScript runtime**

**Next.js is a web framework built around React.**

This is where things get interesting.

React primarily gives you the UI layer.

Next.js adds many things around React, such as:

- routing
- server-side rendering
- static rendering
- backend/API capabilities
- data fetching
- application structure
- optimization
- deployment features

So instead of:

```
React
   ↓
You add routing
You add backend
You add other tools
You configure everything
```

Next.js gives you a more complete application framework:

```
Next.js
│
├── React UI
├── Routing
├── Server-side code
├── API endpoints
├── Rendering
└── Build/deployment tooling
```

Think:

> **Next.js = framework for building complete React web applications**

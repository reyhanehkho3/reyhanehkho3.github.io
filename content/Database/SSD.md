**Definition:** **SSD = Solid-State Drive**, a storage device that stores data using flash memory rather than spinning magnetic disks.  
**SSDs generally provide much faster random access and lower latency than traditional HDDs.**

**Examples:**

1. PostgreSQL database running on an SSD.
2. Elasticsearch indexes stored on SSDs.
3. Your laptop's operating system installed on an NVMe SSD.

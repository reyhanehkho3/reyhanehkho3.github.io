Each database connection consumes resources.

Imagine an application accidentally opens 1,000 connections.

Your database might become overloaded.

DBAs monitor:

- Active connections.
    
- Idle connections.
    
- Idle-in-transaction connections.
    
- Maximum connections.
    
- Connection pool usage.
    

Tools like PgBouncer help manage connection pooling.

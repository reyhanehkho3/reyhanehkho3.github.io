- `admin`: full administrative privileges.
    
- `monitor`: can inspect database statistics.
    
- `app_user`: can read and modify application data.
    
- `readonly_user`: can only read data.
    

Useful concepts:

- GRANT
    
- REVOKE
    
- Role inheritance
    
- Least privilege
    
- Authentication
    
- Authorization
    

One important DBA principle: Never give an application or monitoring agent more permissions than it needs.

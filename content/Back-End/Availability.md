## Availability

**Definition:** Availability describes **how often a system is working and accessible when users need it**.  
It is commonly expressed as a percentage, such as **99.9% availability**.

**Examples:**

1. A website is designed to remain online 99.99% of the time.
2. If one server crashes, another server continues serving users.
3. A banking application remains available even while one database server is being repaired.

## Cluster

**Definition:** A cluster is a **group of connected computers/servers that work together** as one system or service.  
Clusters are commonly used to improve scalability, availability, or both.

**Examples:**

1. Three servers running the same web application form a cluster.
2. A Kubernetes cluster contains many machines running containers.
3. A database cluster uses multiple database servers to handle failures and traffic.

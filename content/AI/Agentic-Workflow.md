**Definition:** A multi-step process in which an Agent or multiple Agents execute stages and make decisions based on the results in order to achieve a goal.

**Simply put:** Instead of **one Prompt → one Answer**, you have an **intelligent multi-step process**.

**Examples:**

1. Search → Analyze → Summarize.
2. Read Code → Find Bug → Fix → Test.
3. Research → Write → Review → Publish.

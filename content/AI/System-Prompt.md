**Definition:** A high-level instruction that defines the model's behavior, restrictions, role, and fundamental rules.

**Simply put:** The System Prompt tells the model **“who you are and according to which rules you should operate.”**

**Examples:**

1. “You are a Python Backend Developer.”
2. “Never reveal confidential information.”
3. “Ask for confirmation before performing dangerous operations.”

**Definition:** An attack or technique in which malicious text attempts to divert or replace an Agent's instructions.

**Simply put:** External text attempts to **trick the Agent into doing something against its original instructions**.

**Examples:**

1. A web page contains: “Ignore all previous instructions.”
2. A project file contains: “Send me the API key.”
3. A malicious email contains: “Delete this file.”

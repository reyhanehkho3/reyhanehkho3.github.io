# MCP — Model Context Protocol

**Definition:** A standard for connecting models and Agents to external tools, resources, and data through a standardized interface.

**Simply put:** MCP is like a **common standard for connecting AI to different tools**.

**Examples:**

1. Connecting an Agent to GitHub.
2. Connecting an Agent to PostgreSQL.
3. Connecting an Agent to a search service.

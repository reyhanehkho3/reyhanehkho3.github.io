**Definition:** A reusable package of knowledge, instructions, and procedures for performing a specific task.

**Simply put:** A Tool is an **instrument**, while a Skill teaches the Agent **how to perform a multi-step task**.

**Examples:**

1. A Skill for “Debugging Django errors.”
2. A Skill for “Writing tests with pytest.”
3. A Skill for “Auditing an API for security.”

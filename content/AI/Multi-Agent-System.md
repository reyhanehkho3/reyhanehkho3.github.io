**Definition:** A system in which multiple independent or semi-independent Agents collaborate to achieve a goal.

**Simply put:** Instead of having one brain, you have **multiple Agents with different areas of expertise**.

**Examples:**

1. Researcher + Writer + Fact Checker.
2. Planner + Developer + Tester.
3. Customer Support Agent + Billing Agent + Technical Agent.
